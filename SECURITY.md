# Security Policy

## Supported Versions

Only the latest version of AnimalMind is actively maintained and receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in AnimalMind, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please:

1. Open a [GitHub Security Advisory](https://github.com/firstoff23/AnimalMind/security/advisories/new) (private disclosure)
2. Or contact the maintainer directly via GitHub: [@firstoff23](https://github.com/firstoff23)

### What to include in your report

- A clear description of the vulnerability
- Steps to reproduce the issue
- Potential impact assessment
- Any suggested fix (optional)

### Response Timeline

- **Acknowledgement**: within 48 hours
- **Initial assessment**: within 5 business days
- **Fix & disclosure**: as soon as possible after validation

## Scope

This policy applies to the AnimalMind application, including:

- Backend API (Node.js / Supabase)
- Frontend client (React / Next.js)
- ML backend (YOLOv8 / Python)
- Android / mobile app

## Out of Scope

- Third-party services (Supabase, Vercel, etc.) — report those directly to the respective provider
- Issues in development/test environments with no production impact

Thank you for helping keep AnimalMind and its users safe.
